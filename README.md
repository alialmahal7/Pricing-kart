# تسعير كرت كرتونة: نسخة GitHub + Firebase

## الملفات

| الملف | شنو |
|---|---|
| `index.html` | الصفحة كاملة، نفس صفحة Claude، ومعاها شاشة دخول |
| `cloud.js` | الربط مع Firebase (الدخول والبيانات والصلاحيات) |
| `firebase-config.js` | إعدادات مشروعك في Firebase (**لازم تملأها**) |
| `database.rules.json` | قواعد الحماية لقاعدة البيانات |

## الصلاحيات

- **owner (إنت):** بتقدر تعمل كل حاجة.
- **editor (زميلك):** بيعدّل **الأسعار وضرايب IATA بس**.
  - السيرفر بيرفض أي تعديل تاني منو، زي الريت والإعدادات والاتفاقية والغرامات والمقترحات وإخفاء الروتات.
  - الأزرار دي ما بتظهر ليهو في الصفحة أصلاً.
- كل تعديل بيتسجّل في **سجل التعديلات** باسم الزول العدّلو.
- لمن تفتح الصفحة، بيطلع ليك تنبيه بعدد التعديلات الجديدة من غيرك.
- لو اتنين عدّلوا نفس القسم في نفس الوقت، التاني بتطلع ليهو رسالة يعمل Refresh. كدا ما في زول بيمسح تعديل زول تاني.

## الخطوات

### 1. نزّل نسخة من بياناتك الحالية
1. افتح صفحة Claude.
2. امشي **الإعدادات**، واضغط **«نزّل نسخة كاملة»**.

بيتنزّل ملف `pricing-backup-YYYYMMDD.json`.

### 2. Firebase
1. افتح https://console.firebase.google.com واعمل مشروع جديد.
2. **Build → Authentication → Get started → Email/Password → Enable**.
3. **Authentication → Users → Add user**: ضيف إيميلك وكلمة سر، وضيف إيميل زميلك وكلمة سر.
   - انسخ **User UID** بتاع كل واحد فيكم.
4. **Build → Realtime Database → Create database**. اختار أقرب منطقة، وابدأ بـ **locked mode**.
5. **استيراد البيانات:**
   1. في تبويب **Data**، اضغط ⋮ ← **Import JSON**.
   2. اختار ملف `pricing-backup-....json` من الخطوة 1.
6. **إضافة المستخدمين:**
   1. في **Data**، جنب اسم قاعدة البيانات اضغط **+**.
   2. ضيف الشكل ده، وبدّل الـ UID بالقيم الحقيقية:
      ```json
      {
        "users": {
          "UID-بتاعك":   { "role": "owner",  "name": "Ali" },
          "UID-زميلك":  { "role": "editor", "name": "اسم زميلك" }
        }
      }
      ```
   ⚠ **الترتيب مهم:** اعمل الاستيراد (خطوة 5) قبل ما تضيف المستخدمين، لأن Import JSON في الجذر بيمسح أي حاجة موجودة.
7. **Rules:**
   1. امسح القواعد الموجودة.
   2. الصق محتوى `database.rules.json`.
   3. اضغط **Publish**.
8. **إعدادات الربط:**
   1. امشي **Project settings (⚙) → General → Your apps → Web (</>)**، وسجّل app.
   2. انسخ القيم من `firebaseConfig`، والصقها في `firebase-config.js`.
   3. اتأكد إنو `databaseURL` فيهو قيمة.

### 3. GitHub Pages
1. اعمل repository، وارفع فيهو `index.html` و `cloud.js` و `firebase-config.js`.
2. **Settings → Pages → Branch: main / root → Save**.

الرابط بيكون زي `https://اسمك.github.io/اسم-الrepo/`.

### 4. اسمح للدومين في Firebase
**Authentication → Settings → Authorized domains → Add domain**، وضيف `اسمك.github.io`.

## ملاحظات أمان
- `apiKey` في `firebase-config.js` عادي يكون ظاهر. الحماية الحقيقية في **Rules**، والصفحة بتفتح بس للناس الإنت ضفتهم في **users**.
- لو الـ repo **عام (public)**، الكود ظاهر للناس لكن **البيانات لا**. الأسعار والاتفاقية في Firebase، ما في الكود.
- **عشان تشيل صلاحية زميلك:** امسح سطرو من `users`، أو عطّل حسابو من Authentication.
- **النسخة الاحتياطية:** من **الإعدادات** في الصفحة الجديدة نفسها (المالك بس)، بنفس الزر.
